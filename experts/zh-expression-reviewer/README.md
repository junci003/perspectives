# Chinese Expression Reviewer

给中文文本和界面做发布前审校。

## 类型

Agent 型（单个 AI 专家）

## 功能

- 文本三档强度（L1 轻 / L2 中 / L3 重）+ T1/T2/T3 三级味单
- 六项量化判据：词汇多样性、句长波动、短语重复、套话命中、标点节奏、语义平滑度
- 界面三类硬指纹：AI 默认色板、emoji 当图标、技术信息泄漏
- `scan_ui_ai_tells.py` 零依赖扫描，`--gate --threshold 45` 可接 CI
- 硬红线：事实零损失、零新增，不许编细节

## 使用示例

- 这篇稿子读起来像 AI 写的，帮我按 L2 强度改一遍，不许加原文没有的事实
- 这个落地页的配色和图标看着很 AI，帮我扫一遍并给修复方案
- 发布前帮我做一次自查，出结论：能不能发、还差什么
