# 失败清单（原文的反向资产）

> 孙子是少数**主动写失败清单**的思想体系。这三份清单比正面原则更可执行。
> 「将有五危」见主文件 SKILL.md。

---

## 兵有六败

> 原文结论：**「凡此六者，非天地之灾，将之过也。」**
> 关键在归因——不怪天，不怪地，不怪运气，怪将领。

| 败象 | 原文定义 | 现代转译 |
|---|---|---|
| **走** | 势均，以一击十 | 实力相当却以少击多，硬拼 |
| **驰** | 卒强吏弱 | 兵强将弱，管理层拖垮执行层 |
| **陷** | 吏强卒弱 | 将强兵弱，战略超出执行能力 |
| **崩** | 大吏怒而不服，遇敌怼而自战，将不知其能 | 中层不服、擅自出战，而主帅不了解其能力 |
| **乱** | 将弱不严，教道不明，吏卒无常，陈兵纵横 | 主帅无威、制度不明、编制混乱 |
| **北** | 将不能料敌，以少合众，以弱击强，兵无选锋 | 判断失误 + 无精锐先锋，全线溃败 |

诊断用法：出现任一败象，先对照原文定义**定性**，再归因到「将之过」的哪一环——
是料敌（判断）、是用众（编制）、是教道（训练）、还是赏罚（激励）。

## 君之三患（上级干预的三种死法）

> 原文：「君之所以患于军者三」

| 患 | 原文 | 表现 |
|---|---|---|
| **縻军** | 不知军之不可以进而谓之进，不知军之不可以退而谓之退 | 不懂前线却强令进退 |
| **军士惑** | 不知三军之事而同三军之政 | 不懂业务却插手管理 |
| **军士疑** | 不知三军之权而同三军之任 | 不懂临机应变却干预指挥 |

> 结论：**「三军既惑且疑，则诸侯之难至矣。是谓乱军引胜。」**
> ——自己搞乱自己，把胜利送给敌人。

对应的正面原则见启发式第 11 条：
「君命有所不受」＋「进不求名，退不避罪，唯民是保，而利于主，国之宝也」。
**裁量权与担责是配套的：要不受君命，就得不求名、不避罪。**

## 战术禁忌（八条，军争篇）

> 高陵勿向，背丘勿逆，佯北勿从，锐卒勿攻，饵兵勿食，归师勿遏，围师遗阙，穷寇勿迫。

| 禁忌 | 含义 |
|---|---|
| 高陵勿向 / 背丘勿逆 | 不仰攻占据高地者、不正面对抗背靠丘陵者 |
| 佯北勿从 | 假装败退的，不要追 |
| 锐卒勿攻 | 精锐部队不要强攻 |
| 饵兵勿食 | 诱饵不要吃 |
| 归师勿遏 | 撤回本土的部队不要拦（会死战） |
| 围师遗阙 | 包围要留缺口 |
| 穷寇勿迫 | 绝境之敌不要逼 |

共同逻辑：**不要主动创造「对方无路可退」的局面。** 因为「投之无所往，死且不北」——
你正在把对手变成最危险的形态。
