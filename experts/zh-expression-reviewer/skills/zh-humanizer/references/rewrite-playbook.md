# 改写手法手册

## 四种手法，按有效性排序

### 手法一：删（最有效，最常被忽略）

大部分 AI 味不需要「换成什么」。**直接删掉，意思不变，就是它本来就该删。**

先删这五类：

1. 段末升华句
2. 万能连接词
3. 形容词副词（先全删，再看哪句塌了）
4. 重复一遍的并列项（三段排比里往往只需要一段）
5. 「值得注意的是」引导的整句——通常后文自己会说明

**判据：删完意思没变 = 它本来就多余。**

### 手法二：拆

- **长句拆短。** 中文节奏靠短句。一句话超过 40 字，找连接处切开。
- **排比拆散。** 三段排比留一段，其余删或改成具体动作。
- **段落拆小。** 一段超过 6 行，考虑切开。
- **定语拆出来。** 多层「的」的定语，提出来单独成句。

### 手法三：换具体

| 抽象 | 换成 |
|---|---|
| 提升效率 | 从三小时变二十分钟 |
| 广泛应用 | 在 A、B、C 三个场景里用过 |
| 存在挑战 | 卡在哪一步，卡了多久 |
| 显著改善 | 数字变了多少 |
| 业内人士 | 谁。说不出来就别写「业内人士」 |
| 多个案例 | 哪个案例。说不出来就写「几个」 |

**这一条的要害：不是你换得漂亮，是你能不能换得出来。换不出来说明原文就是空的——那就删。**

### 手法四：注入特异性

这是唯一治本的。可注入的六种：

1. **数字**——具体到不大好看的程度（「大约两周」比「显著缩短」好，但「11 天」更好）
2. **人名与出处**——谁说的，在哪说的
3. **时间地点**——什么时候、在哪儿发生
4. **一次性细节**——只会发生在这一件事上的东西（「第三版文档的批注里写着…」）
5. **立场**——作者偏向哪边，明确说出来
6. **不确定**——不知道就说不知道，没想清楚就说没想清楚

**第 5、6 条是最被低估的。** 人味不是来自「有趣」，是来自「有立场」和「敢说自己不知道」。模型最不会做的就是这两件事。

## 拿到作者样本时：量五个维度

有样本就照样本改。样本优先于本 skill 的所有规则。

| 维度 | 怎么量 |
|---|---|
| 句长 | 数句子字数。是短句为主（10 字上下），还是长短交错？ |
| 段落 | 一段几行？爱不爱用单句成段？ |
| 标点 | 破折号多不多？有不用感叹号的？引号是全角还是直角？ |
| 开头 | 直接说事，还是先铺一个场景？爱不爱用问句开头？ |
| 口癖 | 反复出现哪些词（「说实话」「其实」「我」）？哪些词从来不用？ |

**特别注意「从来不用」的那一栏。** 一个作者从不写「因此」，你改出来的稿子就不能有「因此」，哪怕语法上没错。

## 一个完整案例

原文（一篇知识管理文章的 AI 初稿开头）：

> 在当今信息爆炸的时代，知识管理已成为个人成长的重要课题。一方面，海量信息为我们提供了前所未有的学习机会；另一方面，信息过载也带来了筛选与内化的挑战。因此，如何在信息洪流中构建属于自己的知识体系，就显得尤为关键。
>
> 首先，我们需要明确知识管理的核心目标。大量研究表明，有效的知识管理能够显著提升个人的学习效率与决策质量。其次，我们需要选择合适的工具。市面上涌现出了众多各具特色的知识管理工具。最后，我们需要建立持续迭代的习惯。值得注意的是，工具只是手段，习惯才是根本。
>
> 知识管理不是简单的信息收藏，而是一场关于认知方式的深层变革。它如同一面镜子，照见我们思考的方式。

**第一步 · 标味**

| 位置 | 标记 | 级别 |
|---|---|---|
| 「在当今信息爆炸的时代」 | 万能时代状语 | T1 |
| 「已成为……的重要课题」 | 空洞大词 | T1 |
| 「一方面……另一方面……」 | 平衡腔 | T2 |
| 「前所未有的学习机会」 | 形容词通胀 | T1 |
| 「因此，如何……就显得尤为关键」 | 段末升华 + 万能连接词 | T1 |
| 「首先／其次／最后」 | 万能连接词 ×3 | T1 |
| 「大量研究表明」 | 无源引用 | T1 |
| 「显著提升」 | 形容词通胀 | T1 |
| 「市面上涌现出了众多各具特色的」 | 形容词通胀 + 空 | T1 |
| 「值得注意的是，工具只是手段，习惯才是根本」 | 段末升华 | T1 |
| 「不是……而是……」 | 中英共有最强标记 | T1 |
| 「如同一面镜子，照见……」 | 万能比喻 | T1 |
| 「知识体系」「认知方式」「深层变革」 | 名词化 + 空 | T2 |

**三段一百八十字，密集命中十个 T1。这段几乎全是填充。**

**第二步 · 问四个问题**

1. 这段到底想说什么？（作者自己可能也不知道——这是 AI 味最深的根源）
2. 有没有真实经历可以放进来？
3. 作者对这件事的态度是什么？
4. 哪些句子删掉，意思一点不丢？

（如果第 1、2、3 条答不出来，**先别改，先问用户要材料**。没有材料只能改出「另一种空」。）

**第三步 · 改写**

假设用户补充了真实材料：他用了三年笔记软件，换了四个工具，最近一次是放弃了某个工具。

> 我用过四个笔记工具。第一个用了两年，里面存了三千多条，最后一条也没再打开过。
>
> 后来我才想明白，问题不在工具。我一直在做的是「收藏」，不是「整理」——看到好文章就存进去，然后就没有然后了。存的时候特别爽，像已经读过了。
>
> 现在我的做法很土：只记三行以内，写完合上。每周花二十分钟翻一遍，把没用的删掉。留下来的通常不到三成。
>
> 这个办法救不了效率。它只保证一件事：我存的那些东西，我真看过。

**第四步 · 复查**

| # | 判据 | 结果 |
|---|---|---|
| 1 | 事实零损失 | ⚠️ **原来那些「事实」全是空话，没有可损失的事实** |
| 2 | 零新增 | ⚠️ **新增了四个工具、三千条、二十分钟、三成**——这些是用户提供的真实材料，不是编的。**如果用户没给，这一条就不过** |
| 3 | 五查 | 无「不是A而是B」✓ 无段末升华 ✓ 无破折号 ✓ 无排比 ✓ 无加粗 ✓ |
| 4 | 删名词测试 | 删掉「工具」「文章」「东西」，意思塌了 ✓ |
| 5 | 盲测 | 认不出是 AI 写的 ✓ |
| 6 | 读出声 | 顺 ✓ |

**注意第 2 条。** 改写的自由度全部来自「用户提供了什么」。**用户给不出真实材料时，正确的动作是：把空话删掉，让文章变短，然后告诉用户「这里需要你补一段真实经历」。** 这比编一段像模像样的假经历负责得多。

## 改写的两个陷阱

### 陷阱一：逐句打补丁

把「因此」换成「所以」、把「显著」换成「明显」、把「不是A而是B」拗成「B，而不是A」——**改完之后骨架一点没动，还是一样空。**

**做法：哪句别扭，就重写它所在的整段。** 先抓住这段真正想说的那一件事，然后围绕它重新组织。

### 陷阱二：改成第二种平均

把所有句子都改成短句、每段都插一句口语、每个观点都加一句「说实话」——**这是用一种均匀替换另一种均匀。**

**做法：不均匀是目标。** 有的段落就是长，有的段落就一句话。有的句子带口语，有的句子正经。真人写作的节奏是参差的，不是整齐的短。

## 交付格式

**对话里贴文本（默认）：** 返回三样——改后正文、改动清单（哪些标记被处理了）、需要用户补材料的地方。

**文件模式：** 用户指定了文件就只写正文进文件。**只改散文。代码块、行内代码、命令、路径、YAML 元数据、数据、链接目标一律不动。** 然后给一句简短说明。

**嵌入模式：** 别的任务（写 PR 描述、commit message、文档）调用我时，只返回最终文本，不加说明。
